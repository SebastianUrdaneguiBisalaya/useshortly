# Security

## Reporting vulnerabilities

Email **sebasurdanegui@gmail.com** only. Do not open public GitHub issues for security bugs.

Please include:

- Steps to reproduce
- Impact (what an attacker could do)
- Whether the issue is already public

We will acknowledge your report and work on a fix. Please do not file a public issue for unfixed vulnerabilities.

## Other contact

- General support: **sebasurdanegui@gmail.com**
- Maintainer: **sebasurdanegui@gmail.com**

## Scope

This policy covers the Template App self-hosted product in **this repository**.

Out of scope:

- Third-party AI models and their APIs
- Operator misconfiguration (exposed secrets, open databases, weak passwords)

## Supported versions

We support security fixes on the current `main` branch and the latest release (beta).

There is no bug bounty program at this time.
