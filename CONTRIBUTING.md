## Security

- Never commit secrets. `.env` is gitignored; `.env.example` documents every
  variable the project uses with empty/placeholder values.
- If you find a security issue, do not open a public issue - see
  [SECURITY.md](./SECURITY.md) (or email the maintainer directly if that file
  doesn't exist yet) instead.

## Questions

Open a discussion or an issue if something in [AGENTS.md](./AGENTS.md) is
unclear or out of date - that file is meant to be kept accurate, not aspirational.
